# Flowers-Classification
A machine learning project implementing a Decision Tree Classifier to predict Iris flower species based on morphological features.

## Overview
This repository contains a simple multiclass classification workflow built with Scikit-Learn using the classic **Fisher's Iris Dataset**. The goal is to classify iris flowers into three distinct species: *Iris setosa*, *Iris versicolor*, and *Iris virginica*.

## Dataset Features
The model uses four numerical measurements (in cm):
* Sepal length
* Sepal width
* Petal length
* Petal width

## Project Structure
* `Flowers-Classification.ipynb`: Data exploration, feature-target separation, train/test splitting, and `DecisionTreeClassifier` fitting/evaluation.

## Tech Stack
* **Language:** Python
* **Libraries:** `scikit-learn`, `pandas`, `numpy`, `matplotlib` / `seaborn`
